## 핵심 변경

- 운하·정기선 등으로 도시를 옮긴 뒤 출항할 때, 실제 출항 위치를 확인해 출발 항구를 보정합니다.
- 항차 상세에서 지나간 해역별 항해일수와 최저·평균·최고 관측 속도를 확인할 수 있습니다. 계절이 바뀌면 구간을 나누어 기록합니다.
- 좁은 패널에서는 항차 목록을 카드로 표시하고, 해역 상세는 한 줄로 간결하게 보여 줍니다. 표 안의 별도 세로 스크롤을 없앴습니다.
- 여름은 빨간색 해 아이콘, 겨울은 파란색 눈꽃 아이콘으로 표시합니다.

## 기록 안내

새 해역 통계는 업데이트 이후 관측한 항해부터 쌓입니다. 기존 기록의 누락된 수치는 채워 넣지 않습니다.
속도는 Navigator에서 관측한 값이며 실제 순간 속도와 다를 수 있습니다. 판독 공백 등으로 해역별 관측 일수의 합이 전체 항차 일수와 다를 수 있습니다.

## 설치 및 업데이트

DHO Navigator 2.2.1 이상에서 `logbook-1.2.0.dho-module`을 설치하세요. 기존 기록을 유지한 채 업데이트합니다.
공식 서명이 포함되어 있으므로 파일을 다시 압축하거나 내용을 변경하지 마세요.
